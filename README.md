# Freshers’ Party 2K26 Invitation Website

An interactive, futuristic Freshers Day Invitation Website built for **Sri Vasavi Engineering College (A)** — **Department of AIML / CAI / CSD**.

## Features
- **Cinematic Dark Luxury Aesthetic**: Metallic gold typography, glassmorphism, and interactive HTML5 particle background.
- **Roll Number Verification System**: Real-time student lookup powered by official student database (`students_master.xlsx`).
- **Authentic Invitation Poster**: Personalized invitation card overlay matching the official reference poster.
- **High Resolution Export**: Download personalized invitation cards as high DPI **PNG** or **PDF**.
- **Fully Responsive**: Optimized for desktop, tablet, and mobile browsers.

## Tech Stack
- React 19
- Vite
- Tailwind CSS v4
- Framer Motion
- Lucide Icons
- HTML-to-Image & jsPDF
- Canvas Confetti

## Quick Start
```bash
npm install
npm run dev
```
